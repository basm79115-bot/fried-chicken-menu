# 🍗 موقع منيو مطعم FRIED CHICKEN

موقع ويب تفاعلي حديث وفاخر لمطعم **FRIED CHICKEN** المتخصص في وجبات وساندوتشات الدجاج المقلي المقرمش.

## 📱 معلومات المطعم الأساسية:
- **اسم المطعم:** FRIED CHICKEN
- **رقم الهاتف والطلبات:** `056465156484` (اتصال مباشر + طلبات واتساب)
- **العنوان والموقع:** 45 شارع النصر الرئيسي، تقاطع مكرم عبيد، بجوار سيتي سنتر مول - مدينة نصر، القاهرة
- **ساعات العمل:** يومياً من 11:00 صباحاً حتى 2:00 بعد منتصف الليل
- **الصورة الخارجية للمطعم:** متوفرة ومدمجة في قسم الفرع الرئيسي والموقع.

## 🌟 مميزات وتصميم الموقع:
1. **تصميم قوي وجذاب (ثيم أصفر ذهبي مع كتابة سوداء بالكامل Yellow & Black):**
   - خلفية باللون الأصفر الذهبي الساطع والمشهور في أشهر مطاعم الفرايد تشيكن العالمية (`#FFD200`).
   - نصوص وعناوين وحدود وأيقونات باللون الأسود الملكي الصريح (`#000000`).
   - بطاقات وظلال بتصميم نيو-بوب عصري فائق الوضوح والتباين.
   - واجهة متجاوبة 100% مع جميع أحجام الشاشات (موبايل، تابلت، كمبيوتر).
   - خطوط عربية فاخرة وواضحة (Cairo & Rubik).

2. **منيو شامل وتفاعلي:**
   - **وجبات فردية:** وجبة 2 قطعة، 3 قطع سوبريم، 4 قطع هيرو، دينر بوكس.
   - **ساندوتشات كرسبي عملاقة:** برجر كلاسيك، زنجر فاير حار، رانش كرسبي تاور، هوني ماسترد كرانش، تويستر رول.
   - **باكتات عائلية وتوفير:** باكت 8 قطع، باكت اللمة 12 قطعة، ميجا بارتي 16 قطعة، باكت تندرز استربس 15 قطعة.
   - **استربس وأجنحة:** تشيكن استربس، أجنحة بافلو حارة، أجنحة باربيكيو، ديناميت بوب كورن.
   - **مقبلات وأطباق جانبية:** تشيزي فرايز، بطاطس حلزونية، أصابع موتزاريلا، حلقات بصل، كول سلو، أرز ريزو.
   - **صوصات ومشروبات:** صوص شيدر، صوص رانش، فاير صوص حار، عصائر طبيعية، كانزات مثلجة، وتشكوليت لافا كيك.

3. **طرق دفع متعددة ومرنة:**
   - **انستا باي (InstaPay):** تحويل فوري مباشر مع زر نسخ رقم الحساب وحقل إدخال تأكيد العملية.
   - **فودافون كاش (Vodafone Cash):** تحويل لمحفظة كاش المخصصة مع زر نسخ المحفظة وتسجيل رقم المحول.
   - **ماستر كارد وفيزا (MasterCard & Visa):** الدفع بالبطاقة البنكية مع المندوب عند الاستلام عبر ماكينة POS أو دفع إلكتروني.
   - **الدفع نقداً (Cash on Delivery):** خيار الكاش التقليدي عند استلام الوجبة.

4. **نظام تتبع الدليفري الحي المباشر (Live Order Tracker):**
   - **البحث برقم الطلب أو الهاتف:** إدخال رقم الطلب (مثل `#FC-9241`) لمعرفة موقعه الفعلي.
   - **مراحل التوصيل الـ 5:** تم الاستلام -> في المطبخ والقلي -> تغليف حراري -> الطيار في الطريق -> تم التسليم.
   - **بيانات كابتن التوصيل:** اسم الطيار مع زر اتصال مباشر به عبر الهاتف.
   - **شريط محاكاة مسار الرحلة:** شريط تقدم متحرك يوضح المسافة المتبقية ووقت الوصول المتوقع بالدقائق.
   - **تكامل تلقائي مع الطلبات:** عند إتمام أي طلب يتم إنشاء كود طلب فريد وفتحه في التتبع فوراً.

5. **تجربة طلب ذكية وسهلة:**
   - **بحث لحظي:** إمكانية البحث عن أي وجبة أو ساندوتش بالاسم أو المكونات فوراً.
   - **تصفية حسب القسم:** فلترة سريعة بالأقسام.
   - **نافذة تخصيص الوجبة (Modal):** اختيار درجة الحرارة (عادي مقرمش / سبايسي حار) وكتابة ملاحظات خاصة للشيف.
   - **سلة طلبات تفاعلية (Shopping Cart Drawer):** حساب فوري للإجمالي وخدمة التوصيل وتحديث الكميات.
   - **إرسال الطلب عبر واتساب (WhatsApp Order):** إنشاء فاتورة ومنشور مفصل جاهز للإرسال على واتساب المطعم بضغطة زر واحدة.
   - **زر اتصال مباشر:** بالرقم المخصص `056465156484`.
